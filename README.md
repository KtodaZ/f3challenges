# F3 Bedrock Monthly Challenge

A web app for tracking and sharing progress in the F3 Bedrock monthly fitness challenge.

## Stack

- [Next.js](https://nextjs.org/)
- [Firebase](https://firebase.google.com/) (Firestore, Auth, FCM, Cloud Functions)
- [Vercel](https://vercel.com/) for hosting

## Getting Started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.
