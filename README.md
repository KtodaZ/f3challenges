# F3 Bedrock Monthly Challenge

A web app for tracking and sharing progress in F3 regions' monthly fitness challenges. Live at [f3challenges.com](https://f3challenges.com).

> Unofficial, community-built project. Not affiliated with or endorsed by F3 Nation, Inc. "F3" is a trademark of F3 Nation.

## Stack

- [Next.js](https://nextjs.org/)
- [Firebase](https://firebase.google.com/) (Firestore, Auth, FCM, Cloud Functions)
- [Vercel](https://vercel.com/) for hosting

## Getting Started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.
